# Sistema de Gestão de Produtos em C

Projeto desenvolvido em linguagem C como atividade acadêmica do curso de Análise e Desenvolvimento de Sistemas.

## Sobre o Projeto

O sistema permite realizar o gerenciamento básico de produtos diretamente pelo terminal, utilizando um menu interativo.

O usuário pode:

* Cadastrar produtos
* Listar produtos cadastrados
* Buscar produtos por nome
* Excluir produtos
* Salvar dados em arquivo `.txt`

Os dados permanecem salvos mesmo após o encerramento do programa.
